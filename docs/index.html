THAE'S REPLAY EXPLORER

Warcraft III replay analyzer & parser

Turn your Warcraft 3 replays into a match library you can search, compare and learn from.

Thae's Replay Explorer is a free Windows tool that parses local Warcraft III .w3g replay files, including custom and LAN games. Also works with W3Champions and Battle.net replays. Review heroes, units, buildings, build orders, APM and chat without launching the game. Supports Warcraft III patch 3.0, The Forsaken Kingdom. Free for non-commercial use.

Features

Replay library

  • Index multiple folders, with separate enable and subfolder controls
  • Picks up new replays automatically
  • Search players, maps, filenames, replay notes and in-game chat
  • Filter by race matchup, team size and patch
  • Filter by where it was played: W3Champions, Battle.net, or other platforms (custom, LAN and older games)
  • Skip games under 2 minutes
  • Sort by newest, oldest, longest, shortest or map name
  • Map preview, players, date and length on every replay
  • Show the replay or map file in File Explorer
  • Rename replay files from Match Analysis or Classic explorer view, with F2 support; favorites and notes are kept
  • Resizable detailed replay list; Classic explorer view with expandable folders and replays
  • Hide identical replay files across folders without deleting them
  • Drag and drop replay files to import and select them
  • Up/Down arrow navigation in both views
  • Right-click a Classic explorer folder to open it in File Explorer

Match analysis

  • Heroes, abilities and levels
  • Units produced, grouped by type
  • Individual building and research entries with start times and FE/T2/T3 tags
  • Items bought
  • APM graph for the whole game
  • All identified unit, hero and building types assigned to each control group during the match
  • Winner of 1v1 and team games
  • Battle.net MMR and APM per player
  • Date, time, patch and game length
  • Classic or Reforged HD icons
  • Hide suspected duplicate orders in build orders and unit, building and upgrade analysis

Build orders

  • Chronological units, heroes, buildings and research from the first five minutes
  • Fast expansion and tier upgrade tags
  • Separate text and image exports for each player
  • Export filenames include the map and player

Favorites & notes

  • Favorite matches and add autosaved replay notes
  • Filter to favorites or matches with notes using clickable icons
  • Enable both filters to include either favorites or replays with notes
  • Search note contents across your library
  • Notes headings highlight matches with notes
  • Export and import favorites and notes as a backup
  • Annotations follow identical replay files across folders

Chat

  • Full in-game chat with time and channel
  • Search and filter by player
  • Hides the duplicate messages in Battle.net replays
  • Copy to the clipboard
  • Export to a text file
  • Adjustable font size and spacing

Save & share matches

  • Copy the actual .w3g file with the duplicate button beside the replay filename
  • Paste into a Discord conversation with Ctrl+V, then review and send the attachment
  • Drag replays from either list view or the match-header filename into apps that accept files
  • Export a player's build order as text or PNG to share just the opening
  • Favorites and notes stay local; export an annotation backup separately

Players & replays

  • Open a player's W3Champions profile
  • Watch the replay in Warcraft III

The app

  • Supports patch 3.0, The Forsaken Kingdom
  • Also works with W3Champions and Battle.net replays
  • Optional race-colored or white player names in the detailed replay view
  • One-click updates from inside the app
  • Remembers folders, filters, window position, selected replay and analysis tab
  • Replays stay on your PC: no uploads, no telemetry
  • Installer or portable ZIP
  • Free for non-commercial use

Warcraft III replay questions

What is a .w3g replay parser?

A parser reads the data and commands saved in a Warcraft III replay file. Thae's Replay Explorer presents that data as a searchable library and match analysis. A replay is not a video: to watch the match play out, use Warcraft III. Learn how to open a .w3g replay.

Can I analyze replays without launching Warcraft III?

Yes. Browse supported replay files and their analysis in the Windows app. Watching the actual match requires Warcraft III, a compatible game version and the matching map.
