Features

Replay library

  • Indexes multiple folders including subfolders
  • Picks up new replays automatically
  • Search players, maps, filenames, replay notes and in-game chat
  • Filter by race matchup, team size and patch
  • Filter by where it was played: W3Champions, Battle.net, or other platforms
  • Skip games under 2 minutes
  • Sort by newest, oldest, longest, shortest or map name
  • Map preview, players, date and length on every replay
  • Show the replay or map file in File Explorer
  • Rename replay files from Match Analysis or Classic explorer view
  • Hide identical replay files
  • Drag and drop replay files
  • Up/Down arrow navigation in both views

Match analysis

  • Heroes, abilities and levels
  • Units produced
  • Buildings and upgrades researched
  • Items bought
  • APM chart
  • Full-match Timeline
  • Control groups
  • Show winner toggle
  • Battle.net MMR and APM per player
  • Date, time, patch and game length
  • Classic or Reforged HD icons
  • Forsaken Kingdom theme and additional simpler themes
  • Hide suspected duplicate orders in build orders and unit, building and upgrade tabs

Build orders

  • Units, heroes, buildings and researched upgrades from the first five minutes
  • Fast expansion and tier upgrade tags
  • Export build order as text or image

Favorites & notes

  • Filter on favorited replays and replays with notes
  • Searchable notes contents

Chat

  • Full in-game chat with timestamps
  • Hides duplicate chat in Battle.net replays

Save & share matches

  • Copy the actual .w3g file by pressing copy button or drag and drop
  • Paste into a Discord conversation with Ctrl+V
  • Drag replays from either list view or the match-header filename into apps that accept files

Players & replays

  • Open a player's W3Champions profile
  • Watch the replay in Warcraft III

The app

  • Supports up to patch 3.0 The Forsaken Kingdom
  • Also works with W3Champions and Battle.net replays
  • One-click updates from inside the app
  • Remembers folders, filters, window position, selected replay and analysis tab
  • Installer or portable ZIP

Warcraft III replay questions

What is a .w3g replay parser?

A parser reads the data and commands saved in a Warcraft III replay file. Thae's Replay Explorer presents that data as a searchable library and match analysis. A replay is not a video: to watch the match play out, use Warcraft III. Learn how to open a .w3g replay.

Can I analyze replays without launching Warcraft III?

Yes. You can browse any replay in this app. Watching the actual match requires Warcraft III, a compatible game version and the matching map.
