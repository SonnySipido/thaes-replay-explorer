Browse your matches. Compare heroes, armies and the decisions that shaped the game. Supports the latest version of Warcraft III: patch 3.0, The Forsaken Kingdom.

Thae's Replay Explorer is a Warcraft III replay analyzer for Windows. Open your .w3g replay folder once; your match library stays indexed and ready to explore.

  1. Install the app

    Open the downloaded installer and follow the setup steps. You can add a desktop shortcut during installation.

  2. Open Replay Explorer

    Press the Windows key, type Replay and open Thae's Replay Explorer.

  3. Choose your replay folder

    Select your Warcraft III replay folder and let it index. Click a match to see its analysis. Include subfolders if you want.

Features

Replay library

  • Indexes your replay folder, subfolders included
  • Picks up new replays automatically
  • Search by player, map or file name
  • Filter by race matchup, team size and patch
  • Filter by where it was played: W3Champions or Battle.net
  • Skip games under 2 minutes
  • Sort by newest, oldest or map
  • Map preview, players, date and length on every replay
  • Resizable replay list

Match analysis

  • Heroes and ability levels
  • Units produced
  • Buildings and upgrades with start times
  • Items bought
  • APM graph for the whole game
  • Control groups and what was in them
  • Winner of 1v1 and team games
  • Battle.net MMR and APM per player
  • Date, time, patch and game length
  • Classic or Reforged HD icons

Chat

  • Full in-game chat with time and channel
  • Search and filter by player
  • Hides the duplicate messages in Battle.net replays
  • Copy to the clipboard
  • Export to a text file
  • Adjustable font size and spacing

Players & replays

  • Open a player's W3Champions profile
  • Watch the replay in Warcraft III
  • Show the replay or map file in File Explorer

The app

  • Supports patch 3.0, The Forsaken Kingdom
  • Works with W3Champions and Battle.net replays
  • One-click updates from inside the app
  • Remembers your folder, settings, window and last replay
  • Replays stay on your PC: no uploads, no telemetry
  • Installer or portable ZIP
  • Free for non-commercial use
