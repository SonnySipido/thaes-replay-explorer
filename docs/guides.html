01 / GET STARTED

How to open a Warcraft III .w3g replay

A .w3g file contains a Warcraft III match's replay data. Thae's Replay Explorer reads it into tables and graphs; Warcraft III plays the match itself.

  1. Download and install the Windows app, then launch Thae's Replay Explorer.
  2. On first launch, select Use this folder if the suggested location contains your replays, or Choose another folder to select their location.
  3. Let the library populate, then select a match. Start with Heroes & units for an overview of each player's army and abilities.
  4. To watch the match, use Watch replay. This requires Warcraft III, a compatible game version and the matching map on your computer.

Example: a replay a friend sent you

Save practice-match.w3g into a folder you added to the app. The library picks up new files automatically. Search for practice-match and select it to open the analysis.

If the replay does not appear

Check that its folder is enabled and that Include subfolders is on if it is nested deeper. Clear library filters, including the short-game and patch filters. A damaged or unsupported replay may not parse; a future patch can require an app update.

02 / YOUR LIBRARY

Where to find Warcraft 3 replay files

The app looks for the Warcraft III BattleNet folder under your Windows Documents folder. Account-specific replays can be deeper in that tree. Your Documents folder may be redirected to OneDrive or another drive, so use File Explorer to find the actual location.

A typical starting point

Documents → Warcraft III → BattleNet

Choose this parent folder and enable Include subfolders to cover account folders beneath it. Downloaded replays may instead be in Downloads or a folder you chose yourself.

  1. Open Settings using the gear in the top-right corner.
  2. Under Replay folder, select Choose folder and pick a location containing .w3g files.
  3. Enable Include subfolders to scan nested folders.
  4. For separate locations, expand Advanced settings and use Add folder. Each location has its own enabled and subfolder controls.

Browse folders in Classic explorer view

Enable Classic explorer view in Settings to show each configured folder as a separate root, then expand folders to reach their replay files. Right-click a folder to open it in File Explorer.

Folders with no replay results in the current view are greyed out and cannot expand. Enable Hide empty folders to remove them from the list; this option is available only in Classic view. Clearing filters can bring folders back when their replays match again.

Choose Longest first or Shortest first in the sorting dropdown to order matches by game duration. In Classic view, replays are sorted within their folders.

Warcraft III replays in one place

Add every location where you save Warcraft III matches, including custom and LAN games. The app also works with W3Champions and Battle.net replays. Use the Platform filter for W3Champions, Battle.net, or Custom, LAN or older games. The app identifies the platform from replay data, not the filename. Renaming a file will not change its platform.

03 / OPENING DECISIONS

Comparing build orders

The Build orders tab lists each player's units, heroes, buildings and research chronologically for the first five minutes. Use Buildings & upgrades to explore building and research timings later in the match.

  1. Select two matches with the same race and a similar matchup. Note the map and game patch; openings can change with either.
  2. Open Build orders and compare the sequence of your first hero, production buildings and tier upgrades.
  3. Read each ability's rank from the vertical bars in Heroes & units. Three segments represent a normal ability's levels; an ultimate has one full bar. Hero levels are inferred from replay events, and exact experience progress is unavailable.
  4. Look for the first meaningful difference, then watch that part of the replay to understand why it happened.
  5. Use the per-player text or image export to keep the opening beside your practice notes.

04 / SAVE & SHARE MATCHES

Saving, sharing and bookmarking replays

Keep matches you want to learn from, then send the actual .w3g file to a friend or coach. A replay attachment lets them inspect the match in Thae's Replay Explorer or watch it in a compatible Warcraft III installation.

1. Keep the match and add a review note

  1. Select a replay and click the favorite star so you can find it again.
  2. Expand Notes under the match header. Record a timestamp and one question you want answered; notes save automatically.
  3. Use the favorites or notes filter beside the library heading, or search the words in your note.

Favoriting a replay bookmarks it; it does not make another copy of the replay file. Keep the original .w3g file in your replay folders.

Rename a replay so it is easy to find

Click the pencil icon beside the filename in Match Analysis, or right-click a replay in Classic explorer view. You can also press F2 for the focused or selected replay.

Enter a name such as Practice - Last Refuge - early expansion and press Rename. The .w3g extension is added automatically, the file stays in its folder, and favorites and notes are preserved. An existing file with the same name will not be overwritten.

2. Copy the replay into Discord

  1. Select the match. Beside its filename, click the copy icon (two overlapping sheets). Hover over it to see the explanation.
  2. Wait for Replay copied. This copies the file to the Windows clipboard, not just its name or path.
  3. Switch to the Discord conversation or channel where you want to share it and press Ctrl+V.
  4. Review the attachment, add your message and send it yourself. Copying in the app does not upload or send anything.

3. Or drag the replay straight into the conversation

Open Discord alongside Replay Explorer, then choose whichever starting point is easiest:

  • Detailed list: drag the replay row from the library on the left.
  • Classic explorer view: expand the folder and drag the replay's filename from the list. Drag a replay, not the folder heading.
  • Match header: drag the filename of the open replay.

Drop it into Discord's message area, review the attachment and send. List dragging uses the replay you grabbed, even if a different match is selected. A normal click still selects a replay; double-click still opens playback. Clicking the match-header filename still reveals the file in Explorer.

Back up favorites and notes

Use Settings → Advanced settings → Export annotations to save a JSON backup of your favorites and notes. Replay files are not included.

To restore annotations on another computer, transfer the replay files too, then use Import annotations. Annotations are matched to identical replay content.

If paste or drag does not attach the file

Clipboard and file-drop support depends on the receiving app. If Ctrl+V does nothing, try dragging; if that fails, click the replay filename to reveal it in File Explorer and use Discord's attach-file control. If Replay Explorer says the file is missing, locate or restore the original replay first. Copying another item replaces the clipboard, so copy the replay again before pasting.

Sharing transfers the replay through Discord or the receiving app. Thae's Replay Explorer itself does not upload it or create a public download link.
