01 / GET STARTED

How to open a Warcraft III .w3g replay

A .w3g file contains a Warcraft III match's replay data. Thae's Replay Explorer reads it into tables and graphs; Warcraft III plays the match itself.

  1. Download and install the Windows app, then launch Thae's Replay Explorer.
  2. On first launch, select Use this folder if the suggested location contains your replays, or Choose another folder to select their location.
  3. Let the library populate, then select a match. Start with Heroes & units for an overview of each player's army and abilities.
  4. To watch the match, use Watch replay. This requires Warcraft III, a compatible game version and the matching map on your computer.

Example: a replay a friend sent you

Save practice-match.w3g into a folder you added to the app. The library picks up new files automatically. Search for practice-match and select it to open the analysis.

If the replay does not appear

Check that its folder is enabled and that Include subfolders is on if it is nested deeper. Clear library filters, including the short-game and patch filters. A damaged or unsupported replay may not parse; a future patch can require an app update.

02 / YOUR LIBRARY

Where to find Warcraft 3 replay files

The app looks for the Warcraft III BattleNet folder under your Windows Documents folder. Account-specific replays can be deeper in that tree. Your Documents folder may be redirected to OneDrive or another drive, so use File Explorer to find the actual location.

A typical starting point

Documents → Warcraft III → BattleNet

Choose this parent folder and enable Include subfolders to cover account folders beneath it. Downloaded replays may instead be in Downloads or a folder you chose yourself.

  1. Open Settings using the gear in the top-right corner.
  2. Under Replay folder, select Choose folder and pick a location containing .w3g files.
  3. Enable Include subfolders to scan nested folders.
  4. For separate locations, expand Advanced settings and use Add folder. Each location has its own enabled and subfolder controls.

Battle.net and W3Champions in one place

Add every location where you save matches, then use the Played on filter to separate Battle.net and W3Champions games. The app identifies the platform from replay data, not the filename. Renaming a file will not change its platform.

03 / OPENING DECISIONS

How to compare Warcraft III build orders

The Build orders tab lists each player's units, heroes, buildings and research chronologically for the first five minutes. Use Buildings & upgrades to explore building and research timings later in the match.

  1. Select two matches with the same race and a similar matchup. Note the map and game patch; openings can change with either.
  2. Open Build orders and compare the sequence of your first hero, production buildings and tier upgrades.
  3. Look for the first meaningful difference, then watch that part of the replay to understand why it happened.
  4. Use the per-player text or image export to keep the opening beside your practice notes.

Review the lead-up to 2:40. Was there extra unit production, an expansion, or pressure at home? The timestamps identify where to look; they do not establish the cause.

Orders are not confirmed completions

Replays record player commands. Repeated clicks and cancellations can create entries for things that never finished. Treat production counts and start times as command-derived estimates, and confirm uncertain events by watching the match. A repeated order alone is not proof of another completed unit.

04 / READ THE MATCH

How to read APM in a Warcraft 3 replay

APM means actions per minute. The graph helps locate changes in activity across the match, but a high value does not by itself demonstrate better decisions or more effective play. Repeated inputs can contribute to activity.

  1. Open the APM tab and compare each player's graph over the same period.
  2. Identify a spike or a quieter stretch, then note its match time.
  3. Watch that section of the replay. Check whether the player was fighting, managing the base, travelling or repeatedly issuing commands.
  4. Use the other analysis tabs to add context: a new hero, a technology order or chat may help explain the moment.

Example review question

“My activity rises around 6:00. During that fight, did I keep producing units and protect my hero?” Review the replay at that time, then write down one concrete adjustment. APM alone cannot answer the question.

05 / KEEP WHAT YOU LEARN

Find, save and share useful replays

Build a small collection of matches you can return to. Search supports player names, maps, filenames, replay notes and in-game chat; matchup, team-size, platform and patch filters help narrow the library.

  1. Select a useful match and mark it with the favorite star.
  2. Expand Notes and write the moment to revisit and what you want to practice. Notes save automatically.
  3. Use the favorite or notes filter beside the replay-library heading to find annotated matches again.
  4. Under Settings → Advanced settings, use Export annotations to back up favorites and notes. Keep the .w3g files separately: the annotation backup does not include them.

A useful replay note

Focus: earlier tech
2:40 — compare production before tech
6:00 — review hero positioning during the fight
Next practice: check the base when the army moves out

Later, search for earlier tech to find this note and its replay.

Share the right file

Click the replay filename in the match header to reveal the .w3g file in File Explorer. Share that file if someone needs the full replay, or export a player's build order if they only need the opening. Check chat and player names before sharing publicly.
