# Warcraft theme artwork

These original materials were generated with the built-in image_gen tool using the imagegen skill, from the visual direction of the user's interface mockup. The PNGs are preserved as generated; the metal frame has a transparent center and is used as a CSS nine-slice border. Artwork is bundled for offline use.

Files: `metal-frame.png`, `dark-wood.png`, `forest-backdrop.png`.

## Metal frame prompt

Use case: stylized-concept. Asset type: a production-ready nine-slice border texture for a Warcraft-inspired desktop game interface. Generate ONE square 1024 by 1024 PNG asset: an ornate rectangular hammered gunmetal frame seen straight-on, perfectly aligned to the four edges of the canvas. The large central rectangle must be genuinely transparent; outside the frame must also be transparent. The frame is an approximately 72-pixel-thick band, with all corner ornamentation contained within 128 by 128 pixel corner areas. Dark charcoal forged steel, sculpted silver bevel highlights, aged brass inner trim, black recesses, visible small round rivets, restrained lime-green patina in the upper corners, angular clipped corners. The four long straight edge sections should be simple and continuous so a CSS border-image can stretch them horizontally and vertically. Hand-painted high-detail early-2000s fantasy RTS UI art, matching the metal and wood interface in the user's mockup. The frame must have a dark recessed inner lip with a narrow bright silver outer highlight and restrained gold detailing. No wood or material in the transparent central area. No text, logos, emblems, portraits, scenery, UI controls, drop shadows extending beyond the canvas, or extra objects. This is a usable standalone frame texture, not a screenshot or concept sheet.

## Wood material prompt

Use case: stylized-concept. Asset type: seamless repeating wood texture for the banners and headers of a fantasy RTS desktop interface. Generate one square 1024 by 1024 image of very dark walnut and scorched mahogany wood, viewed perfectly straight on, with fine horizontal grain and a few subtle long plank seams. Painterly early-2000s Warcraft-style interface material: rich brown grain, almost black crevices, restrained worn warm highlights, no large knots, no objects, no bolts, no trim, no symbols and absolutely no text. Keep the brightness evenly distributed and subdued enough that gold and white UI text will remain legible on top. Tile seamlessly on all four edges. The wood material fills every pixel of the canvas, opaque background. This is one raw reusable material texture, not a mockup or an asset sheet.

## Forest backdrop prompt

Use case: stylized-concept. Asset type: subdued full-window background artwork for a Warcraft-inspired fantasy replay-analysis desktop app. Generate one wide landscape image, 1536 by 1024, showing an ancient moonlit forest valley with distant jagged slate cliffs, very dark layered pine silhouettes, and restrained blue mist. Early-2000s hand-painted fantasy RTS menu background, serious and atmospheric. Palette: near-black navy, deep blue slate and charcoal; subtle steel blue rim light, no bright highlights. The entire upper half should be especially quiet and dark; the trees and rocky silhouettes mainly run along the lower third and outer edges. Composition should remain attractive when cropped to different desktop window aspect ratios. No characters, creatures, faces, buildings, text, logos, interface panels or buttons. This is reusable opaque background art, not a UI screenshot.
